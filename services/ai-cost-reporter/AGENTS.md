# Codex / coding-agent instructions

## Goal
Keep this application a small auditable Docker/Dokploy daily job that retrieves **actual provider-recorded OpenAI and xAI API costs**, writes PDF + JSON snapshots, and delivers both to CoinCourier-owned Google Drive. New installations use an authenticated Google Apps Script receiver under `AI Infrastructure Costs / YYYY / MM`. Delivery is enabled by `GOOGLE_DRIVE_ENABLED=true` and selected by `GOOGLE_DRIVE_BACKEND=apps_script`; an unset backend defaults to legacy `oauth` for compatibility. Email/WhatsApp may remain optional.

## Non-negotiables
- Never read, commit, print, log, request or upload credentials. `.secrets/`, `.env`, credential files and live reports are Git-ignored and Docker-ignored. Any legacy Desktop OAuth client JSON remains outside the repository in the user's Downloads directory.
- Previously disclosed OpenAI Admin and xAI Management keys MUST be revoked and replaced before deployment. Never reuse disclosed credentials.
- No production API requests with demo/test credentials. Automated tests use mocks only. `--no-send` still queries live billing; `--demo` is offline.
- Require successful responses from BOTH cost APIs. An error is not $0. Cost figures come from billing APIs, never inferred from token counts.
- Keep scope explicit: `OPENAI_PROJECT_IDS` blank means organization-wide; otherwise only those OpenAI projects are requested. xAI reports the configured team, without an assumed per-project breakdown.
- Execute the job at 09:00 `Europe/Belgrade`; billing periods are complete UTC days. Late billing creates snapshot/reconciliation considerations.
- Apps Script's shared secret is a new random 32-byte value represented by exactly 64 lowercase hex characters, stored only in Script Properties and protected Dokploy variables. The HMAC key is the literal text's UTF-8 bytes, not hex-decoded bytes. Do not use earlier OAuth client secrets for this backend.
- Match the canonical LF-separated HMAC-SHA256 protocol in Python and Apps Script exactly, including the replacement flag and raw-byte hashes. Body signatures are required; Apps Script does not document custom-header access. Enforce a ±300-second timestamp window and durable bounded replay protection before any Drive operation.
- Bound and validate both report files and the JSON response. HTTP 200 is not delivery success: require `ok: true` and the expected date, filenames, hashes and file IDs. `doGet` must never disclose or access Drive data.
- Preserve snapshots and backend/destination delivery markers on persistent `/data/reports`. Reuse exact artifacts after partial failure; sign retries with fresh authentication. Same-name differing bytes require explicit `--force-resend`; replacements preserve Drive IDs through Advanced Drive v3. Fail on ambiguous existing names. `--no-send` must not overwrite an existing marked snapshot; use a separate output directory for live billing previews.
- Do not store credentials in Docker layers, Git or generated PDF/JSON. Use one reporter replica, protected environment variables and persistent report storage.
- Python: type hints, docstrings, single-quoted strings, explicit failures and no bare `except: pass`.
- Do not provision, deploy, push or run live billing/Drive smoke tests without user authorization. Manual Google account consent is separate from offline verification.

## Google delivery boundaries
- Apps Script is owned and authorized by CoinCourier. The receiver runs as the owner with anonymous web-app access; HMAC protects uploads. The endpoint is public, while Drive contents and script-editing access stay private. Organizational restrictions may prevent this access setting.
- The manifest enables Advanced Drive v3 and full `https://www.googleapis.com/auth/drive` owner authorization. This is broader than the legacy OAuth backend's `drive.file`; review and explain the consent during manual setup.
- `AI_COST_SHARED_SECRET` is entered in Script Properties and the same literal value in protected Dokploy `GOOGLE_APPS_SCRIPT_SHARED_SECRET`. Optional `AI_COST_PARENT_FOLDER_ID` identifies a private CoinCourier My Drive parent. Leave `GOOGLE_OAUTH_*` blank for Apps Script.
- Never put a secret in the `/exec` URL, source, request logs or custom headers. Google ContentService responses redirect to `script.googleusercontent.com`; only bounded validated JSON establishes success.
- Legacy OAuth remains separately configurable. The Desktop JSON is never mounted in a remote container; only protected `GOOGLE_OAUTH_CLIENT_ID`, `GOOGLE_OAUTH_CLIENT_SECRET` and `GOOGLE_OAUTH_REFRESH_TOKEN` are configured there. An External Gmail OAuth consent screen must be In production to avoid Testing-mode seven-day refresh-token limits; revocation, inactivity and Google security policy can still invalidate tokens. Do not run the local consent helper without explicit authorization.
